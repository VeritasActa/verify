# Project governance

`@veritasacta/verify` is maintained by Tom Farley ([@tomjwxf](https://github.com/tomjwxf)),
through ScopeBlind. It is an open-source project with a single lead maintainer,
not a foundation-governed standard or an independently governed certification body.

## Decisions and releases

Anyone may file an issue, propose a fixture or submit a pull request. The maintainer
decides scope, reviews changes, merges contributions and authorizes releases.
Changes to formats, trust rules and exit behavior should be discussed in a public
issue before implementation. Security reports follow the private process in
[SECURITY.md](SECURITY.md).

Decisions should be explained in the issue or pull request, with reproducible
evidence where behavior is disputed. Ask for reconsideration there if new evidence
changes the conclusion. There is no separate steering committee or formal voting
process at present. This document will be updated if stewardship changes.

## Scope and independence

The verifier implements checks; a relying party decides whom to trust and whether
the evidence is sufficient. Interoperability contributions do not constitute an
endorsement or a commercial relationship. The Internet-Drafts are individual
proposals, not adopted IETF standards.

ScopeBlind's commercial services are separate from use of this repository. The
license and patent notice are [LICENSE](LICENSE) and [PATENTS.md](PATENTS.md).
No account or paid service is required to contribute or run the offline verifier.

## Working together

Be specific, respectful and focused on evidence. Do not publish another person's
private data, credentials or sensitive security report. The maintainer may moderate
spam, harassment and disclosure of private information; moderation decisions can
be queried at tommy@scopeblind.com.
